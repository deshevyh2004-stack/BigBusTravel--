# BIG-BUS Travel — перенесення з Floot

## Стан на 07.11.2026
- Репозиторій містить демонстраційний `index.html` із чорно-червоним оформленням.
- Нинішня версія зберігає `routesData`, `bookingsData`, `parcelsData` у `localStorage` браузера. Це **не спільна база даних**, отже реальні бронювання клієнтів не синхронізуються між пристроями.
- У демонстраційному HTML є тестові облікові дані адміністратора, вбудовані в JavaScript. **Не можна використовувати їх для живої адмінпанелі**.
- Початковий репозиторій публічний. **Не комітити** паспортні дані, списки клієнтів, телефони, паролі, токени, ключі чи знімки бази.
- Робочий сайт на Floot поки не вимикати: дані з нього ще не мігровано.

## Безкоштовна архітектура (з обмеженнями тарифів)
1. Cloudflare Workers для HTTPS API, Cloudflare Pages / Workers Static Assets для фронтенду.
2. Cloudflare D1 як спільна SQL-база. Унікальні обмеження + транзакційна перевірка зайнятих місць; жодних `localStorage`-бронювань у production.
3. Безпечна серверна авторизація адміністратора та водія; сесії в HTTP-only cookies. Паролі — тільки хешовані, ніяких облікових даних у HTML.
4. Google Sheets — вторинний облік, а не єдине джерело правди. Синхронізація через серверні Google OAuth credentials / service account (у secret store), із журналом імпортів/експортів та ідемпотентністю.
5. Сайт залишається українським, у чорно-червоній палітрі. Урахувати вибір місць 7/41, проміжні зупинки, адреси, QR-квитки, посилки й багаж.
